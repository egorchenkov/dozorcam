Ваши камеры, ваш Telegram, без облака

Dozorcam следит за IP-камерами на вашем Linux-узле, находит людей и шлёт снимки и клипы в forum-группу Telegram: у каждой камеры своя тема, плюс тема «Пульт» с состоянием всей системы.

Что умеет

Буфер записи в RAMКольцевой буфер на каждую камеру в tmpfs: моменты вокруг события под рукой, а SD-карта и диск не изнашиваются.
Люди, а не листьяДетектор движения с порогом шума на камеру, затем ONNX-детектор людей (по умолчанию YOLOX-Tiny) и фильтр неподвижных предметов.
Интерфейс — TelegramСнимки и клипы по событию и по запросу, пауза, переименование, снятие камеры — кнопками в теме камеры.
Настройка из чатаОдноразовый код в логах делает вас владельцем; бот сам заводит темы и ищет камеры по ONVIF / WS-Discovery.
Модели и порогиМодели YOLOX, YOLOv5 или в стиле YOLOv8 переключаются из бота на ходу; порог на каждую камеру калибруется по шуму сцены.
Компактно и закрытоОдин мультиархитектурный образ (amd64, arm64) для движка и бота: не root, корневая ФС только на чтение, без capabilities, healthcheck.

Установка в 3 шага

Нужен Linux (amd64 или arm64) с Docker и плагином compose; узлу нужен доступ к api.telegram.org.

  1. Создайте бота. В Telegram откройте @BotFather, отправьте /newbot и скопируйте токен.
  2. Запустите Dozorcam с этим токеном: 
    git clone https://github.com/egorchenkov/dozorcam.git && cd dozorcam
cp .env.example .env && sed -i 's/^CCTV_BOT_TOKEN=.*/CCTV_BOT_TOKEN=<токен>/' .env
docker compose pull --ignore-pull-failures && docker compose up -d
    Релизный образ — ghcr.io/egorchenkov/dozorcam; если скачать его не удалось, compose соберёт образ локально.
  3. Станьте владельцем. docker compose logs bot | grep SETUP покажет одноразовый код — отправьте боту в личку /start <код>. Затем создайте группу с включёнными Темами, добавьте бота администратором («Управление темами», «Удаление сообщений») и отправьте /add, чтобы подключить камеры.

Какие камеры подходят

ЧтоКак подключается
ONVIF (Profile S)Находится сама (локальные сети /24 и WS-Discovery); адреса потока и снимка — через ONVIF Media.
Любая RTSP-камера/add rtsp://хост:порт/путь; снимок берётся из потока.
Hikvision (ISAPI)Встроенные шаблоны RTSP и /ISAPI/Streaming/channels/101/picture, где ONVIF молчит; гейт по людям от аналитики самой камеры — по желанию.

Проверено вживую на камерах Hikvision G0/G2/G5 и Tantos. Камеру нужно заранее активировать средствами производителя. Другие производители должны работать через ONVIF/RTSP, но не проверялись.

Как это выглядит

# Двор · тема камеры

👤 Обнаружен человек · Двор · 14:02:19

🎞 Клип вокруг кадра📷 Кадр🎞 Клип 30 с🔄 Статус

У каждой камеры своя тема. Срабатывание приходит снимком с рамкой детектора; кнопки под ним собирают клип вокруг этого момента из буфера, присылают свежий кадр или состояние камеры.

В теме «Пульт» — состояние системы, меню модели детектора (/model) и пороги по камерам.

Картинки на странице — иллюстрации: нарисованная сцена и настоящие надписи кнопок бота. Записей с реальных камер здесь нет.

Языки

Бот говорит по-русски и по-английски и подстраивается под язык Telegram (/lang en|ru — сменить). Другие языки планируются.

Лицензия

Dozorcam распространяется под Apache-2.0. В образе есть YOLOX-Tiny (Apache-2.0) и сборка FFmpeg под GPL-3.0-or-later — см. THIRD_PARTY.md. Веса YOLOv5/YOLOv8 (AGPL-3.0) не поставляются, их можно добавить самостоятельно.
